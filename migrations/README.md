# Миграции БД

Здесь будут миграции схемы (goose), применяемые сервером при старте под
advisory-lock. Первая миграция появится на этапе 1 и будет основана на
[`../docs/db/schema.sql`](../docs/db/schema.sql).

На этапе 0 (каркас) сервер не подключается к базе данных; проверить схему можно
скриптом [`../docs/db/verify.sql`](../docs/db/verify.sql).
